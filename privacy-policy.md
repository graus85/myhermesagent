# Privacy Policy — Hermes Agent
_Last updated: September 2026_
## Overview
Hermes Agent is a personal automation assistant used solely by its owner (Andrea Gracis) to interact with his own Google Workspace account (Gmail, Calendar, Drive, Sheets, Docs, Contacts, Tasks) via the Google APIs.
This is **not** a public or commercial application. It is not distributed to other users and does not collect, store, sell, or share any personal data belonging to third parties.
## Data Access and Use
Hermes Agent accesses the following Google services, strictly for the owner's own account and only to perform actions the owner explicitly requests:
- **Gmail** — read, send, and organize the owner's own email
- **Google Calendar** — read and manage the owner's own calendar events
- **Google Drive** — read, upload, and manage the owner's own files
- **Google Sheets / Docs** — read and edit the owner's own documents and spreadsheets
- **Contacts** — read the owner's own contacts
- **Tasks** — read and manage the owner's own task lists
All data retrieved through these APIs is used only to fulfill the owner's direct requests (e.g., "check my calendar", "send this email", "create this event") and is not transmitted to, stored by, or shared with any third party.
## Data Storage
OAuth credentials (access and refresh tokens) are stored locally on the owner's own private server and are used exclusively to authenticate API requests made on the owner's behalf. No data retrieved via these APIs is persisted beyond what is needed to complete the requested action, unless explicitly saved by the owner (e.g., to a local file at the owner's own request).
## Third-Party Sharing
No data is shared with third parties. No data is sold. No data is used for advertising.
